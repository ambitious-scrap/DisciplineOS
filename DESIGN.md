# DESIGN.md — DisciplineOS Visual System

## 1. Visual Archetype & Language
- **Aesthetic Family:** OLED Tactical Cyber-Hardware (Linear-tier precision meets machined aerospace telemetry).
- **Core Canvas:** Void Obsidian (`#030712`) with refractive glass overlays (`#0B0F19`/90 backdrop-blur-2xl) and ambient cyan/indigo mesh lighting.
- **Elevation Model:** **Double-Bezel (Doppelrand) Nested Architecture**. Containers feature a micro-hairline outer shell with concentric curved inner glass panels (`rounded-[1.25rem]` with `rounded-[calc(1.25rem-1.5px)]`).

## 2. Typography Hierarchy
- **Display & Headings:** `Plus Jakarta Sans` (weights 600, 700, 800) with tight tracking (`tracking-tight`).
- **Telemetry, Signatures & Numbers:** `JetBrains Mono` (weights 500, 600) for crypto signatures, countdown timers, package identifiers, and audit hashes.
- **Body & Captions:** `Plus Jakarta Sans` (weights 400, 500) in high-contrast crisp text (`text-slate-100`, `text-slate-400`).

## 3. Color Tokens & Semantic Roles
- **Canvas Base:** `#030712` (OLED Obsidian)
- **Card Surface:** `#0B0F19` (Void Slate)
- **Primary Kinetic Accent:** `#38BDF8` (Core Cyan) / `#3B82F6` (Laser Blue)
- **Verified / Earned State:** `#10B981` (Emerald Proof)
- **Active Warning / Lock:** `#F59E0B` (Sovereign Amber)
- **Emergency Penalty:** `#F43F5E` (Emergency Crimson)

## 4. Component Rules
- **Interactive Buttons:** Button-in-button trailing icon pattern with kinetic hover tension (`active:scale-[0.98]`).
- **Time Bank HUD:** Holographic SVG radial arc gauge paired with live progress meter and particle bursts.
- **Audit Logs:** Cryptographic badge indicators with HMAC-SHA256 signature verification pills.
- **Anti-Patterns Banned:** Banned Inter default, banned AI-purple gradients, banned flat grey borders, banned 1-line CTA button wrapping.
